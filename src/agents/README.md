# src/agents

`AgentDefinition`s for the catalogued journeys: `agent.execute` (J2, structured), `agent.observe`
(J1, human) and `agent.focus` (J7–J15, focus/search/code intents). Composed in
`src/app/runtime.ts`; only ids in `JOURNEY_AGENTS` may start.

Canonical documentation: [docs/subsystems/semantic-execution.md](../../docs/subsystems/semantic-execution.md)
and [docs/subsystems/focus-engine.md](../../docs/subsystems/focus-engine.md).
